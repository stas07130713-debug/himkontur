ЗАГРУЖАЙТЕ В РЕПОЗИТОРИЙ СОДЕРЖИМОЕ ЭТОЙ ПАПКИ ЦЕЛИКОМ.

Это исходный проект ХИМКОНТУР, подготовленный 20.09.2026.
Папки node_modules, dist, release, временные файлы и результаты проверок
в репозиторий не загружаются.

Обязательно сохраните структуру каталогов, включая скрытую папку:
  .github\workflows

Для обновления через GitHub Desktop:
1. Откройте локальную папку ранее созданного репозитория himkontur.
2. Скопируйте в неё всё содержимое папки «ХИМКОНТУР-ГОТОВО-ДЛЯ-GITHUB»
   с заменой файлов.
3. В GitHub Desktop в поле Summary напишите:
   Автономная карта и обновление аварийных карточек
4. Нажмите Commit to main.
5. Нажмите Push origin.

Файл автономной карты:
  public\map-data\monchegorsk-v5.pmtiles
Он обязателен для работы карты без интернета.
