Автономная карта ХИМКОНТУР

Файл monchegorsk-v5.pmtiles подготовлен из ежедневной сборки Protomaps
от 20.09.2026 на основе данных OpenStreetMap.

Границы пакета: 31.515°–34.215° в.д., 67.495°–68.355° с.ш.
Масштабы: 0–15.

Файл monchegorsk-satellite-v1.pmtiles содержит автономную спутниковую подложку
EOX Sentinel-2 cloudless 2016 для тех же границ, масштабы 0–13. На более близких
масштабах приложение использует локальное увеличение последнего уровня без
сетевых запросов.

Обе подложки, их переключение, приближение, отдаление и схема работают без
подключения к интернету. Подложка показывается только после полной отрисовки
видимого кадра, поэтому при переключении не появляются пустые квадраты.
