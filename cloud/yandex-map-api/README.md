# Облачная синхронизация карты ХИМКОНТУР

Серверная функция хранит актуальную карту района выезда и историю изменений в YDB Serverless.

Переменные окружения функции:

- `YDB_CONNECTION_STRING` — строка подключения YDB;
- `ADMIN_PASSWORD` — общий пароль режима настройки карты.

Функция запускается от сервисного аккаунта с ролью `ydb.editor`. Ключи сервисного аккаунта не создаются: авторизация выполняется через метаданные среды выполнения.

Клиенты обращаются только к публичному HTTPS-адресу функции. Чтение доступно без авторизации, запись требует общего административного пароля. После публикации новая ревизия становится доступна всем устройствам при очередной фоновой проверке.

Актуальный рабочий адрес:

- `https://functions.yandexcloud.net/d4eqi6k1daj25oqpk6bp`

GitHub Actions раз в 10 минут сохраняет резервную копию облачной базы в `public/data/district-map.json`.
