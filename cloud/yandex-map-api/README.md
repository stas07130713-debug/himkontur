# Основная база карты ХИМКОНТУР в Яндекс Cloud

Серверная функция хранит актуальную карту района выезда и историю изменений в YDB Serverless.

Переменные окружения функции:

- `YDB_CONNECTION_STRING` — строка подключения YDB;
- `ADMIN_PASSWORD` — общий пароль переходного прямого режима;
- `PRIMARY_SYNC_TOKEN` — общий секрет с Cloudflare Worker;
- `ALLOWED_ORIGINS` — разрешённые источники через запятую;
- `REQUIRE_BASE_REVISION=true` — запрещает запись без базовой версии;
- `REQUIRE_COORDINATOR_WRITES=true` — после включения Cloudflare запрещает прямые записи по паролю.

Функция запускается от сервисного аккаунта с ролью `ydb.editor`. Ключи сервисного аккаунта не создаются: авторизация выполняется через метаданные среды выполнения.

Протокол версии 2 добавляет идентификаторы операций и проверку базовой версии. Повтор одного `operationId` безопасен: функция возвращает уже сохранённый результат и не применяет изменение второй раз. Сначала эту версию следует развернуть с `REQUIRE_COORDINATOR_WRITES=false`, проверить запись через Worker, а затем включить обязательную запись только через координатор.
