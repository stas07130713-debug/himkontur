# ХИМКОНТУР 0.3.61

Исправления синхронизации общей карты и проверки расчётов.

- Пакет сохраняется до отправки вместе с неизменяемым содержимым и идентификатором. Потеря ответа, повтор и перезапуск больше не должны подменять следующую местную правку предыдущей.
- Сервер хранит подтверждения независимо от очистки очереди зеркалирования; повтор с другим содержимым отклоняется. Только подтверждённые объекты снимаются с очереди.
- Карта и очередь сохраняются одной атомарной локальной записью. Повторяющиеся объекты в снимках не дублируются в хранилище. Прежний формат мигрирует автоматически при успешном сохранении.
- Автоматическое получение работает и при местной очереди: независимые правки объединяются; более свежая серверная редакция спорного объекта применяется с сохранением конфликта в журнале. Серверное удаление не восстанавливается из старой местной копии.
- Получение выполняется при открытии, возвращении в окно, восстановлении сети и периодически (настройка сервера — 30 секунд). Во время активной отправки применение входящей карты откладывается до завершения попытки, затем запрашивается сразу.
- Для полной загрузки сервер закрепляет снимок на 24 часа. Все порции проверяются по общей контрольной сумме. Изменение рабочей карты не прерывает чтение закреплённого снимка; истёкший снимок перезапрашивается с ограничением числа повторов.
- Исправлена транзакция журнала изменений при конкурентных записях: отклонённая запись не попадает в поток обновлений.
- Расчёт отклоняет неконечные числовые значения, неизвестные типы разлива/устойчивости и повреждённые координаты.
- Публикация сайта и приложений теперь требует прохождения автоматических проверок.

Порядок развёртывания: резервная копия D1; добавочная миграция 0003 (существующие карты и журналы не удаляет); обновление Worker; проверка чтения; публикация браузерной, Windows и Android сборок. Старые клиенты продолжают использовать прежние маршруты, новый протокол применяется после обновления клиента.

Не изменяются расчётные формулы, оформление путёвки, круговые контуры, отсечение невидимых объектов и отрисовка один раз за кадр. Работа без сети сохраняется; получить данные из облака при физически отсутствующей связи невозможно.

Проверено перед выпуском: npm run check — успешно; 166 клиентских тестов (1 ранее пропущен), 30 серверных, 2 desktop. Браузерная приёмка — 177/177. Резервная копия D1 сохранена до добавочной миграции.
