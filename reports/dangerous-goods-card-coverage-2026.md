# Покрытие аварийных карточек опасных грузов

- Строк автономного транспортного справочника: 3122.
- Уникальных UN в транспортном справочнике: 2315.
- Строк, однозначно сопоставленных официальной АК: 3116.
- Строк, для которых официальная АК в нормативном комплекте не найдена или назначение неоднозначно: 6.
- Строк исходного индекса АК: 3252.
- Уникальных вариантов отображения UN + наименование + АК: 3230.
- Уникальных UN с назначенной АК: 2323.
- Официальных АК: 331.
- Потерянных связей внутри официального индекса UN → АК: 0.
- Исходная АК содержит все семь разделов: 3057.
- В исходной АК один или несколько разделов не выделены отдельно; интерфейс показывает связанное общее требование этой же АК без жёлтой заглушки: 173.
- Групповых назначений: 3160.
- Индивидуально уточнённых профилей: 2323.

Карточка в программе всегда строится из назначенной официальной АК. Во всех семи рабочих разделах выводится текст этой карточки; проверенные индивидуальные сведения имеют приоритет. Для групповой АК область действия обозначена прямо, чтобы общий текст не выдавался за индивидуальное свойство вещества. Строки без официального назначения перечислены отдельно и не получают выдуманную карточку.
