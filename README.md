# Рабочая версия «ХИМКОНТУР»

Единое приложение на React и строгом TypeScript с оболочками Electron для Windows и Capacitor для Android. Расчетное ядро не зависит от компонентов интерфейса; нормативные таблицы, геодезия и независимая проверка вынесены в отдельные модули.

## Запуск

Готовые установочные файлы находятся в корневой папке `Готовые приложения`.

Из корня проекта дважды щелкнуть `Запустить первую версию.cmd`. Альтернативно из этой папки:

```powershell
npm install
npm run dev
```

Контроль качества и production-сборка:

```powershell
npm run check
```

## Реализовано

- расчёт по 35 нормативным вариантам АХОВ из таблицы В.3 СП 165.1325800.2014;
- табличная интерполяция, ограничения области применимости и трасса формул;
- независимый повторный вычислитель с тремя статусами проверки;
- один редактируемый источник, размещение касанием или мышью;
- контрольные точки, геодезическое расстояние, относительное и абсолютное время подхода;
- ручная погода и необязательный запрос Open-Meteo;
- два режима карты, компас, направление ветра, динамический масштаб;
- локальное сохранение сценария в IndexedDB;
- единообразные отчёты Word и PDF с исходными данными, трассой формул и выбранной картой;
- автономный поиск опасного груза по номеру ООН, названию, химической формуле и номеру опасности;
- локальное распознавание номера ООН и номера опасности с фотографии, ручная проверка и обязательное подтверждение пользователем;
- 266 официальных аварийных карточек Минтранса России, перенесённых из PDF без подмены отсутствующих сведений общими рекомендациями;
- service worker и кэширование приложения со справочником для работы без сети после первого запуска.

## Границы первой версии

- Распознанный текст карточек получен из официальных PDF. До допуска к реальному оперативному применению каждая оцифрованная карточка должна пройти документированную построчную сверку специалистом; интерфейс не называет OCR-перенос нормативной верификацией.
- Официальный железнодорожный комплект не содержит однозначной карточки для каждого номера UN современного перечня ADR. Если связь не установлена официальным указателем, программа не показывает выдуманные рекомендации и сообщает, что карточка не сопоставлена.
- Транспортный справочник требует отдельного формального контроля изменений таблицы A ADR 2025; карточка Минтранса и запись ADR показываются как разные источники и не смешиваются.
- Это прототип системы поддержки решений, а не допущенный к оперативному применению расчетный комплекс.

## Нормативные источники справочника

- ADR 2025: официальный портал ЕЭК ООН — <https://unece.org/ru/node/395825>;
- аварийные карточки и указатели: официальный комплект Минтранса России — <https://www.mintrans.gov.ru/documents/6/825>;
- альтернативная официальная точка доступа к карточкам: Росжелдор — <https://rlw.gov.ru/rule_moving>.

## Структура

- `src/core` — формулы, таблицы, валидация, проверка и геодезия;
- `src/ui` — адаптивный интерфейс;
- `src/storage` — локальное хранилище;
- `desktop` — защищенная Windows-оболочка и локальный сервер приложения;
- `android` — нативный проект Android;
- `capacitor.config.ts` — конфигурация мобильной оболочки;
- `public/data/dangerous-goods.tsv` — автономный справочник;
- `public/data/emergency-cards.json` — автономная оцифровка официальных аварийных карточек и сопоставление с UN;
- `scripts/build-official-emergency-cards.mjs` — воспроизводимая сборка карточек из официальных PDF;
- `scripts/build-official-un-index.mjs` — сопоставление UN с карточками по официальному указателю;
- `dist` — готовая production-сборка.
