# Как опубликовать ХИМКОНТУР и открыть его на телефоне

## Один раз подготовить репозиторий

1. Установите GitHub Desktop и войдите в свой аккаунт GitHub.
2. Откройте **File → Add local repository → Choose** и выберите эту папку.
3. GitHub Desktop сообщит, что папка пока не является репозиторием. Нажмите ссылку **create a repository**, не меняя расположение папки.
4. В поле имени укажите `himkontur`, ветку оставьте `main` и завершите создание.
5. Внизу слева введите описание первого изменения, например `Первая версия`, и нажмите **Commit to main**.
6. Нажмите **Publish repository**. Имя оставьте `himkontur`; снимите флажок **Keep this code private**, чтобы GitHub Pages был доступен без входа.
7. Нажмите **Publish Repository** и дождитесь окончания загрузки.

## Включить публикацию

1. На странице репозитория откройте **Settings → Pages**.
2. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
3. Откройте вкладку **Actions** и дождитесь зелёной отметки у процесса «Публикация ХИМКОНТУР».
4. Адрес будет иметь вид `https://ВАШЕ_ИМЯ.github.io/himkontur/`.

## Открыть на телефоне

1. На компьютере нажмите **Мобильная версия** сразу после кнопки **Сохранить расчёт**.
2. Если программа открыта с GitHub Pages, правильный адрес и QR-код появятся автоматически.
3. Если запущена настольная версия, один раз вставьте адрес GitHub Pages в поле окна. Программа его запомнит.
4. Отсканируйте QR-код камерой телефона.
5. Android: меню Chrome → **Установить приложение**. iPhone: Safari → **Поделиться → На экран Домой**.

## Последующие обновления

После изменений выполните в GitHub Desktop **Commit to main**, затем **Push origin**. GitHub автоматически пересоберёт мобильную версию по тому же адресу; QR-код менять не потребуется.

Важно: расчёты и автономный справочник работают после первого полного открытия. Для получения погоды и загрузки ещё не просмотренных фрагментов карты требуется интернет.
